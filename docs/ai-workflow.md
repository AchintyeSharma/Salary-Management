# Agentic AI Workflow & Verification Log

This document records how AI tools were used intentionally during design, implementation, and verification — including concrete issues caught during human/multi-agent review and how every output was verified.

## Operating Discipline

1. **Requirements and design before code.** One-page product scope (`docs/requirements.md`), data invariants (`docs/design.md`), and the phased delivery plan (`ImplementationPlan.md`) were audited and committed before scaffolding application files.
2. **Independent plan review before implementation.** The implementation plan was reviewed for scope discipline, write-path concurrency risks, monetary precision, and security gaps before writing code.
3. **Bounded vertical slices with co-located tests.** Each commit delivered one working vertical slice (API + UI + Vitest/Supertest/PostgreSQL tests), verified with `npm run build`, `npm run typecheck`, `npm run test:unit`, and `npm run test:integration` before moving on.
4. **Independent numerical and runtime verification.** Financial fixtures (multi-country FX totals, even-cohort half-up median, deactivation/reactivation parity) were calculated independently and asserted against live PostgreSQL 16 and a real Chromium browser via Playwright.
